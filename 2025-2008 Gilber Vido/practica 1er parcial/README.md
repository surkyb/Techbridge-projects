Este proyecto es una calculadora matemática básica desarrollada en Java, creada como práctica del primer parcial.
Permite al usuario ingresar dos números y realizar operaciones aritméticas fundamentales desde la consola.

El programa está diseñado aplicando principios básicos de Programación Orientada a Objetos (POO), 
como encapsulamiento y uso de métodos para procesar operaciones.

==== Funcionamientos ====

La calculadora permite realizar las siguientes operaciones:

Ingresar dos números
sumar
Restar
Multiplicar
Dividir (con validación para evitar división entre cero)
Salir del programa

==== cómo funciona ====

El programa muestra un menú en consola.

El usuario selecciona una opción.

Si elige ingresar números, estos se almacenan en el objeto.

Puede ejecutar las operaciones las veces que desee.

El ciclo se repite hasta que el usuario seleccione 0 (Salir).

El flujo se controla mediante un do-while y un switch.

===== Cómo ejecutar =====

Abrir el proyecto en Apache NetBeans o cualquier IDE compatible con Java.

Ejecutar la clase CalculadoraMatematica.

Interactuar con el menú desde la consola.
