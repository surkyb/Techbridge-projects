# Sistema de Vehículos

Programa sencillo en Java que representa vehículos y calcula un costo estimado de mantenimiento. Fue desarrollado como práctica de Programación Orientada a Objetos (POO), constructores y sobrecarga de métodos.

## Funcionalidad

* Crear vehículos con distintos constructores.
* Guardar placa, marca y modelo.
* Calcular mantenimiento según kilómetros.
* Calcular mantenimiento según kilómetros y tipo de servicio.

## Clases

**Vehiculo:** contiene datos del vehículo y métodos para calcular mantenimiento.
**SistemaDeVehiculo (Main):** prueba el funcionamiento del sistema.

## Ejecución

Ejecutar:

```
SistemaDeVehiculo.java
```
