# Sistema de facturación — Empresa de Telefonía

Este programa en Java simula de forma sencilla el funcionamiento de una empresa de telefonía. Fue desarrollado como práctica de Programación Orientada a Objetos (POO), usando clases, encapsulación y cálculos automáticos.

## Funcionalidad

El sistema permite:

* Crear clientes con su número y plan.
* Definir planes con minutos, datos y precio mensual.
* Registrar consumo real.
* Calcular cargos extra por excedentes.
* Generar una factura con el total a pagar.

## Clases principales

**Cliente:** guarda nombre, número y plan.
**Plan:** define minutos, datos y precio mensual.
**Factura:** calcula cargos extra y monto total, y muestra la factura.
**EmpresaDeTelefonia (Main):** prueba el sistema creando clientes y facturas.

## Ejecución

Ejecutar:

```
EmpresaDeTelefonia.java
```

El programa mostrará en consola las facturas generadas.

## Objetivo

Práctica de:

* Programación Orientada a Objetos
* Encapsulación
* Uso de constructores
* Cálculos automáticos dentro de clases
