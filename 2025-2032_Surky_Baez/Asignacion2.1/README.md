# Asignación 2.1 

En esta asignación se creó una clase Tv con sus atributos y métodos, y una clase Prueba donde se instancian tres objetos diferentes para probar su funcionamiento.

SOBRE EL PROYECTO: 

Tv.java Es una clase con los atributos: marca, pulgadas, encendido, volumen
publicos con fines educativos, teniendo en cuenta que no hay encapsulacion.

y tambien posee los métodos (encender, apagar, subir volumen, bajar volumen).


Prueba.java: Es una clase principal donde se crean 3 televisores y se ejecutan sus métodos.

Al ejecutar el programa se muestran en consola los datos de cada TV y las acciones realizadas por sus métodos.
