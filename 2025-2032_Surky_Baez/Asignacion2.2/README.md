# Asignación 2.2 – Sobrecarga de Métodos

Esta práctica fue realizada para aplicar el concepto de sobrecarga de métodos (Method Overloading) en Java.

## Descripción
Se creó una clase Calculadora que contiene métodos para:

- Sumar
- Restar
- Multiplicar
- Dividir

Los métodos sumar, restar y multiplicar fueron sobrecargados para trabajar con:
- 2 parámetros
- 3 parámetros
- 4 parámetros

Menos el método dividir que solo fue implementado con 2 parámetros como se pedía.

También se creó una clase Prueba para demostrar el funcionamiento de todos los métodos.

## Estructura del proyecto

- `Calculadora.java` → Contiene los 10 métodos implementados.
- `Prueba.java` → Clase principal donde se prueban todas las operaciones.

## Ejecución

Al ejecutar el programa se muestran en consola los resultados de cada operación con diferentes cantidades de parámetros.
