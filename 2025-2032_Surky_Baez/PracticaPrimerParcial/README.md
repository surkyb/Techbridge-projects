Calculadora Matemática 

Este proyecto consiste en una calculadora básica desarrollada en Java, capaz de realizar operaciones matemáticas simples utilizando dos números ingresados por el usuario mediante un menú interactivo en consola.

Funcionalidades:

Ingresar dos números
Sumar
Restar
Multiplicar
Dividir (con validación de división por cero)
Menú interactivo en consola

Estructura del Proyecto:

El programa está compuesto por dos clases principales:

CalculadoraMatematica
Contiene los atributos numero1 y numero2
Implementa los métodos de operaciones matemáticas
Valida la división entre cero
PracticaPrimerParcial

Contiene el método main
Permite la interacción con el usuario mediante un menú
Captura datos usando Scanner
