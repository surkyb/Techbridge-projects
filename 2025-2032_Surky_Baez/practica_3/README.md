# Registro Académico - Calculadora de Calificaciones

## Descripción

Esta es una aplicación de escritorio desarrollada en **Java con Swing** que permite registrar los datos de un estudiante y sus calificaciones.
El sistema calcula automáticamente la **nota final** y muestra si el estudiante **APROBÓ o REPROBÓ** la materia.

## Estructura de calificación

* **Prácticas:** máximo 40 puntos
* **Parciales:** máximo 20 puntos
* **Asignaciones:** máximo 20 puntos
* **Examen Final:** máximo 20 puntos

El estudiante **aprueba si obtiene 60 puntos o más**.

## Funcionalidades

* Registro de **nombre, matrícula y carrera**
* Ingreso de calificaciones
* Validación de campos vacíos
* Validación de valores numéricos
* Cálculo automático de la nota final
* Mensaje de **APROBADO** o **REPROBADO**

## Estructura del proyecto

```
src/
├── Estudiante.java
├── RegistroAcademicoGUI.java
└── Main.java
```

## Cómo ejecutar

1. Abrir el proyecto en **NetBeans** o cualquier IDE de Java.
2. Ejecutar la clase **Main.java**.
3. Ingresar los datos del estudiante y presionar **"Calcular y Registrar"**.
