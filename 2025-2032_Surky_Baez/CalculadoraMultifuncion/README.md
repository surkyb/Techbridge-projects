# Calculadora y Conversor de Temperatura en Java

Este proyecto es una aplicación desarrollada en Java utilizando la biblioteca gráfica Swing. La aplicación permite realizar operaciones matemáticas básicas y también convertir temperaturas entre grados Celsius y Fahrenheit mediante una interfaz gráfica sencilla.

El objetivo del proyecto es aplicar conceptos básicos de programación orientada a objetos, manejo de interfaces gráficas y validación de datos ingresados por el usuario.

## Funcionalidades

La aplicación incluye dos módulos principales:

### Calculadora

La calculadora permite realizar las siguientes operaciones:

* Suma
* Resta
* Multiplicación
* División
* Raíz cuadrada
* Exponentes

La calculadora valida que el usuario ingrese valores antes de realizar una operación y evita errores como la división entre cero.

### Conversor de temperatura

El conversor permite transformar temperaturas entre:

* Celsius a Fahrenheit
* Fahrenheit a Celsius

También se validan los valores ingresados para asegurar que el usuario introduzca números válidos, incluyendo números negativos.

## Estructura del proyecto

El proyecto está organizado en varias clases, cada una con una responsabilidad específica:

* **VistaCalculadora**: contiene la interfaz gráfica y la interacción con el usuario.
* **Calculadora**: maneja las operaciones matemáticas básicas.
* **ConversorGrados**: realiza las conversiones entre Celsius y Fahrenheit.
* **RaizCuadrada_Exponente**: contiene los métodos para calcular raíces cuadradas y exponentes.

Esta separación permite mantener el código organizado y seguir el principio de separar la lógica del programa de la interfaz gráfica.

## Tecnologías utilizadas

* Java
* Java Swing
* Programación Orientada a Objetos
