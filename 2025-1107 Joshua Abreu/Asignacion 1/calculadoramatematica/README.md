Calculadora Matemática en Java

Este proyecto consiste en una calculadora matemática básica desarrollada en Java que permite realizar operaciones aritméticas simples mediante un menú interactivo en consola. El programa utiliza la clase CalculadoraMatematica, la cual encapsula la lógica principal del sistema y aplica conceptos fundamentales de la programación orientada a objetos.

La clase CalculadoraMatematica contiene dos atributos privados de tipo double, numero1 y numero2, que almacenan los valores ingresados por el usuario. Para asignar estos valores, se utiliza el método setNumeros, el cual permite establecer ambos números de manera controlada. Las operaciones matemáticas se realizan a través de los métodos sumar, restar, multiplicar y division, cada uno encargado de devolver el resultado correspondiente según la operación seleccionada.

El método division incluye una validación que verifica si el segundo número es igual a cero, evitando así errores en tiempo de ejecución y mostrando un mensaje informativo cuando la división no es posible. El método main se encarga de la ejecución del programa y de la interacción con el usuario mediante un menú que se repite hasta que el usuario decide salir.

La interacción con el usuario se realiza utilizando la clase Scanner, que permite capturar los números y la opción seleccionada en el menú. Mediante una estructura switch, el programa controla cada opción del menú y ejecuta el método correspondiente según la operación elegida.

Este proyecto tiene como finalidad reforzar el uso de métodos, encapsulación de datos, estructuras de control y entrada de datos por consola, aplicando los principios básicos de la programación orientada a objetos en Java.
