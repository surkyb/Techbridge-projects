Este proyecto consiste en una práctica básica desarrollada en Java cuyo objetivo es aplicar los conceptos fundamentales de la programación orientada a objetos, tales como clases, objetos, atributos y métodos. El programa simula el funcionamiento de una televisión mediante la creación de varios objetos de tipo TV. 

El sistema crea tres televisiones con diferentes características como marca, tamaño en pulgadas, estado de encendido y nivel de volumen. A cada objeto se le asignan valores específicos y posteriormente se ejecutan métodos que representan acciones comunes de una televisión, como encender, apagar, subir volumen y bajar volumen. Cada acción muestra un mensaje en la consola para indicar la operación realizada. 

El proyecto está compuesto por dos clases principales. La clase TV contiene los atributos marca, pulgadas, volumen y encendido, además de los métodos que simulan el comportamiento de la televisión. La clase Prueba contiene el método main, desde donde se crean los objetos, se inicializan sus atributos y se llaman los métodos correspondientes. 

Este proyecto tiene como finalidad reforzar el uso de clases y métodos en Java, así como la correcta instanciación de objetos y la comprensión del funcionamiento básico de la programación orientada a objetos.
