Calculadora con Sobrecarga de Métodos en Java

Este proyecto consiste en una calculadora desarrollada en Java que utiliza la técnica de sobrecarga de métodos para realizar operaciones matemáticas con diferentes cantidades de parámetros. La clase principal, llamada Calculadora, implementa métodos que permiten sumar, restar y multiplicar utilizando dos, tres o cuatro valores, demostrando el uso de métodos sobrecargados dentro de la programación orientada a objetos. También incluye un método para realizar la división cuando se emplean únicamente dos parámetros.

La clase Calculadora define varios métodos con el mismo nombre, pero con distinto número de argumentos, lo cual permite ejecutar la misma operación adaptándose a diferentes entradas. Por ejemplo, el método sumar cuenta con tres versiones: una que recibe dos números, otra que recibe tres y una tercera que recibe cuatro. Lo mismo ocurre con los métodos restar y multiplicar. Esta estructura evidencia cómo Java permite reutilizar el nombre de un método siempre que su firma sea distinta, logrando así una mayor claridad y organización en el código.

En el método main se crea un objeto de la clase Calculadora y se realizan distintas pruebas que muestran el funcionamiento de los métodos sobrecargados. El programa ejecuta operaciones con dos parámetros, luego con tres y finalmente con cuatro, imprimiendo en consola los resultados correspondientes. Esto permite verificar que cada versión de los métodos es correctamente invocada según la cantidad de argumentos utilizados.

Este proyecto tiene como propósito reforzar el uso de métodos, la organización adecuada del código y, principalmente, el concepto de sobrecarga de métodos, el cual es una característica fundamental en la programación orientada a objetos en Java.
